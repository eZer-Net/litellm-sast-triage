# Конфигурация

Единый файл `.env` расположен в корне приложения. Флаги `--project`, `--scan`, `--resultName` имеют приоритет над настройками `.env`. SAST-отчёт ищется **внутри выбранного проекта**, результаты сохраняются в `output/` приложения. Не публикуйте `AI_API_KEY`.

| Переменная | Пример/значение | Назначение |
|---|---|---|
| `AI_BASE_URL` | `https://llm.example.com/v1/chat/completions` | Адрес LiteLLM/OpenAI-совместимого API chat completions |
| `AI_API_KEY` | `<secret>` | Ключ авторизации; не добавлять в Git |
| `AI_MODEL` | `your-model-id` | Имя модели на шлюзе |
| `AI_PROTOCOL` | `json` | `json` — текстовые команды, `native` — нативные вызовы функций |
| `AI_TEMPERATURE` | `0` | Температура генерации; для воспроизводимости рекомендуется 0 |
| `AI_TIMEOUT_SECONDS` | `120` | Таймаут HTTP-запроса, секунды |
| `AI_MAX_RETRIES` | `3` | Число повторов при сбое API/сети |
| `AI_RETRY_BACKOFF_SECONDS` | `3` | Пауза перед повтором API, секунды |
| `AI_REQUEST_PAUSE_SECONDS` | `2` | Пауза между запросами модели, секунды |
| `ALERT_PAUSE_SECONDS` | `60` | Пауза между алертами, секунды |
| `PROJECT_DIR` | `` | Директория проекта; пустое значение — интерактивный ввод; приоритет у `--project` |
| `SCAN_FILE` | `scan-all.json` | Имя/относительный путь отчёта внутри проекта; приоритет у `--scan` |
| `RESULT_NAME` | `triage-result-ai` | Префикс автоматического имени с датой и временем (`дд.мм.гггг-ЧЧ-ММ-СС`); `--resultName` задаёт своё имя |
| `PROMPT_FILE` | `prompt.txt` | Файл инструкций модели относительно корня приложения |
| `TAINT_DEPTH` | `5` | Лимит полезных запросов чтения кода на алерт |
| `MAX_WHOLE_FILE_LINES` | `350` | Предельное число строк для чтения целого файла |
| `CONTEXT_MODE` | `smart` | Стратегия чтения: `window`, `smart`, `symbol` |
| `CONTEXT_BEFORE` | `12` | Строки контекста до находки |
| `CONTEXT_AFTER` | `12` | Строки контекста после находки |
| `MAX_SYMBOL_LINES` | `120` | Максимальный размер функции/класса в строках |
| `MAX_BLOCK_LINES` | `200` | Максимальное число строк в возвращаемом блоке |
| `MAX_FIND_MATCHES` | `30` | Ограничение найденных совпадений |
| `MAX_FIND_BLOCKS` | `4` | Ограничение блоков поиска |
| `MAX_TOOL_ERRORS` | `4` | Максимальное число ошибочных/отклонённых запросов инструментов |
| `MAX_PROTOCOL_ERRORS` | `4` | Максимальное число неразбираемых ответов модели |
| `MAX_TOTAL_TURNS` | `25` | Общий лимит обращений к модели на алерт |
| `TRACE_ENABLED` | `true` | Включить журнал JSONL с действиями и ответами |
| `TRACE_INCLUDE_CONTENT` | `true` | Записывать сообщения и код в trace; конфиденциально |
| `TRACE_MAX_CHARS` | `100000` | Ограничение длины строки в trace |

**Пример:** `python3 agent.py --project /repos/app --scan reports/findings.json --resultName audit`.

Без `--resultName` создаётся имя с локальными датой и временем, например `triage-result-ai-13.10.2026-09-14-30`. Одна основа имени используется для `.json`, `.md` и `.trace.jsonl`. Интерактивный режим спрашивает, нужно ли своё имя. Уже существующие результаты не перезаписываются: при совпадении добавляется суффикс `-01`. Двоеточие исключено для совместимости с Windows.
