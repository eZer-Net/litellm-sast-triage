# Адаптер SAST: подключение сканера

**Файл:** `src/sast_triage/parsers/sast.py`. `parse_scan(path)` читает отчёт и возвращает массив находок; `normalize_alert(raw)` приводит одну находку к единому внутреннему формату.

| Поле | Обязательно | Контракт |
|---|---|---|
| `name` | Да | Непустое название правила/находки |
| `path` | Да | Путь к исходному файлу **относительно выбранного проекта** |
| `start.line` | Да | Положительное число, нумерация с 1 |
| `end.line` | Да | Положительное число, нумерация с 1, не раньше start |
| `start.col`, `end.col` | Нет | Номера столбцов, если доступны |
| `cwe` | Нет | CWE или описание, по умолчанию пустая строка |
| `message` | Нет | Описание сканера, по умолчанию пустая строка |

**Шаги:** (1) Настроить `parse_scan()` на массив находок нового сканера. (2) Привести поля в `normalize_alert()` к указанному контракту. (3) Добавить тест формата. Ядро, запрос к ИИ и генератор отчёта менять не требуется.

```python
return {
    'name': raw['rule_id'], 'path': raw['location']['file'],
    'start': {'line': raw['location']['start_line']},
    'end': {'line': raw['location']['end_line']},
    'cwe': raw.get('cwe', ''), 'message': raw.get('description', ''),
}
```

**Безопасность:** исходники читаются без изменений в пределах выбранной директории. Координаты должны соответствовать просканированной версии файлов.
